# Sources

- [Game Balance](https://www.routledge.com/Game-Balance/Schreiber-Romero/p/book/9781498799577) by Ian Schreiber and Brenda Romero — numeric relationships, cost curves, randomness, progression, statistics, metagame and transitive/intransitive systems.
- [A Course About Game Balance](https://www.gdcvault.com/play/1023349/A-Course-About-Game) by Ian Schreiber, GDC 2016 — practical curriculum and exercises for balance work.
- [Game Balance Concepts](https://gamebalanceconcepts.wordpress.com/) by Ian Schreiber — freely available course material, including intransitive relationships and balance vocabulary.
- [Machinations Framework Basics](https://machinations.gitbook.io/docs/getting-started/framework-basics) — model game economies as resource sources, pools, drains, converters, traders and gates.
- [Machinations Documentation](https://machinations.io/docs) — simulations, Monte Carlo analysis and economy diagrams.
- [Breaking down the metagame design in a mobile RPG](https://www.gamedeveloper.com/design/breaking-down-the-metagame-design-in-a-mobile-rpg) — King designers describe interdependent combat, progression and chest systems plus simulation tooling.
- [Defining Loot Tables in ARPG Game Design](https://www.gamedeveloper.com/design/defining-loot-tables-in-arpg-game-design) — controlled randomization, item bases, affixes and level-based tables.
- [Meaningful Decisions & Opposition](https://www.riotgames.com/en/urf-academy/opposition) by Riot Games URF Academy — evaluate balance through opposition and meaningful decisions, not numeric equality alone.

Use source models to expose assumptions. Final tuning must use the actual rules, target audience and playtest data of the game.
