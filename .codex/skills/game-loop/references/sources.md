# Sources

## Game design foundations

- [MDA: A Formal Approach to Game Design and Game Research](https://www.cs.northwestern.edu/~hunicke/MDA.pdf) by Robin Hunicke, Marc LeBlanc and Robert Zubek — connect authored mechanics, emergent dynamics and player aesthetics during iterative design.
- [Game Programming Patterns](https://gameprogrammingpatterns.com/) by Robert Nystrom — canonical free reference for game loop, state, command, event queue, update and other implementation patterns.
- [Meaningful Decisions & Opposition](https://www.riotgames.com/en/urf-academy/opposition) by Riot Games URF Academy — opposition, player decisions, iteration and core loops in an educational curriculum.
- [Pacing](https://book.leveldesignbook.com/process/preproduction/pacing) from The Level Design Book — plan beats, intensity, rest and activity variation while treating documents as hypotheses to playtest.

## Official Godot documentation

- [Scene organization](https://docs.godotengine.org/en/stable/tutorials/best_practices/scene_organization.html) — Main, World and GUI ownership and scene transition considerations.
- [Change scenes manually](https://docs.godotengine.org/en/stable/tutorials/scripting/change_scenes_manually.html) — delete, hide and detach tradeoffs for memory, state and processing.
- [Pausing games and process mode](https://docs.godotengine.org/en/stable/tutorials/scripting/pausing_games.html) — SceneTree pause behavior, processing modes and pause UI.
- [SceneTree](https://docs.godotengine.org/en/stable/classes/class_scenetree.html) — scene switching, timers, groups, pause and frame-level tree operations.

The phrase “game loop” is overloaded. Confirm whether a source is discussing the engine update loop, a player activity loop, a session structure or application state flow before applying it.
