# Sources

Prefer Godot's stable documentation matching the project's declared engine version. Consult `latest` only to investigate upcoming behavior and verify compatibility before using it.

## Official Godot documentation

- [Scene organization](https://docs.godotengine.org/en/stable/tutorials/best_practices/scene_organization.html) — scene independence, ownership, dependency injection and tree relationships.
- [Best practices](https://docs.godotengine.org/en/stable/tutorials/best_practices/index.html) — scenes, scripts, nodes, Autoload, data and logic guidance.
- [Project organization](https://docs.godotengine.org/en/stable/tutorials/best_practices/project_organization.html) — filesystem organization and naming.
- [Nodes and scenes](https://docs.godotengine.org/en/stable/getting_started/step_by_step/nodes_and_scenes.html) — core scene composition model.
- [Scene unique nodes](https://docs.godotengine.org/en/stable/tutorials/scripting/scene_unique_nodes.html) — stable same-scene references and alternatives.
- [Resources](https://docs.godotengine.org/en/stable/tutorials/scripting/resources.html) — typed, serialized, Inspector-editable definition data and shared-resource behavior.
- [Change scenes manually](https://docs.godotengine.org/en/stable/tutorials/scripting/change_scenes_manually.html) — memory and processing tradeoffs during scene changes.
- [Pausing games and process mode](https://docs.godotengine.org/en/stable/tutorials/scripting/pausing_games.html) — pause semantics and per-node processing.
- [Debugger panel](https://docs.godotengine.org/en/stable/tutorials/scripting/debug/debugger_panel.html) — script and visual profiler responsibilities.
- [Performance](https://docs.godotengine.org/en/stable/tutorials/performance/index.html) — measurement-led optimization and server alternatives.
- [Fixing jitter, stutter and input lag](https://docs.godotengine.org/en/stable/tutorials/rendering/jitter_stutter.html) — frame pacing and latency diagnosis.
- [Using TileMaps](https://docs.godotengine.org/en/stable/tutorials/2d/using_tilemaps.html) — TileMapLayer organization, quadrant behavior and baked navigation guidance.
- [Navigation](https://docs.godotengine.org/en/stable/tutorials/navigation/index.html) — navigation maps, regions, agents and optimization.

## Established engineering reference

- [Game Programming Patterns](https://gameprogrammingpatterns.com/) by Robert Nystrom — state, command, observer, component, event queue, object pool and update patterns. Apply patterns only when their tradeoff matches the observed problem.
